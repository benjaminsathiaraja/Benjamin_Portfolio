# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built with HTML5, CSS3, and JavaScript. Designed to showcase academic background, technical skills, certifications, and projects for **Benjamin Sathia Raja S**.

## Features

* **Single-Page Navigation**: Smooth scrolling links targeting all major sections.
* **Single-Line Header Layout**: Optimized navbar layout with no text wrapping across desktop screens.
* **Dark / Light Mode**: Built-in theme toggle with smooth CSS color transitions.
* **Interactive Contact Form**: Integrated with Formspree for direct email submissions.
* **Responsive Design**: Mobile-first media queries including a collapsible mobile navigation drawer.
* **CSS Animations**: Dynamic floating elements, glow effects, and scroll-triggered visibility.

---

## Sections Included

* **Hero Section**: Bio, key role, call-to-action buttons, social links, and profile image.
* **About Me**: Brief personal introduction and core personality traits.
* **Education**: Interactive timeline detailing academic achievements.
* **Experience**: Internship details highlighting technical exposure.
* **Skills**: Grid view of core programming languages and soft skills.
* **Certifications**: Showcase of verified certificates complete with PDF links.
* **Projects**: Highlighted software projects with descriptions and GitHub links.
* **Contact**: Address/email cards along with a functional message form.

---

## Tech Stack

* **Structure**: HTML5
* **Styling**: CSS3 (Flexbox, CSS Grid, Custom Properties/Variables)
* **Interactivity**: JavaScript (ES6+)
* **Icons**: [Font Awesome 6](https://fontawesome.com/)
* **Typography**: Google Fonts ([Inter](https://fonts.google.com/specimen/Inter))
* **Form Handling**: [Formspree](https://formspree.io/)
